\section*{Abstract}

Managing a specialty store that sells books, records, and collectibles requires consistent information about its catalog, stock, sales, and merchandise receiving. Keeping these records in separate tools makes it difficult to verify availability and trace completed operations. To address this need, \textbf{Archivum: Bibliotheca \& Discos} was developed as a web application that combines a public catalog with administrative inventory and sales functions.

The application is implemented with Laravel 13 and PHP 8.4, using MariaDB 11.2 as its relational database. Docker Compose coordinates the PHP-FPM application, database, and Nginx web server. Blade provides the views, while Vite and Tailwind CSS build the interface assets. The data model relates products and their book, record, and collectible specializations to SKU variants, branch stock, unique items, inventory movements, carts, reservations, orders, payments, shipments, and returns.

Implemented features include catalog search and filtering, user registration and authentication, password recovery, product and supplier administration, merchandise receiving, stock adjustments and transfers, order tracking, returns management, and report exports. The online checkout flow is simulated and uses five-minute stock reservations. Curated catalog data can be synchronized through an Artisan command and a version-controlled seeder. The automated test suite completed with 190 passing tests and 1,335 assertions; no load or concurrent stress tests were run.
