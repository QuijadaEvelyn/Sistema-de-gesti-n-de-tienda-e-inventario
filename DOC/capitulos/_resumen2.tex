\begin{_abstract1}
This document explains how we planned, designed, and built the web system ARCHIVUM — Bibliotheca \& Discos. It is a complete online platform to manage stock and sell books, CDs, vinyl records, and collector's items. Unlike normal online stores, this system can handle both regular products with many copies and rare, limited-edition items. Rare items need special tracking with Certificates of Authenticity (COA), and the store can work across different branches.

We built the platform using PHP 8.4 and the Laravel 13 framework with the Model-View-Controller (MVC) structure. It uses a MariaDB 11.2 database, and the web pages are made with HTML5, CSS3, and JavaScript. Everything runs inside Docker and Docker Compose, keeping the app, the Nginx web server, and the database in separate parts. This makes the system easy to move, keeps media files safe, and helps it run the same way every time it is launched. The system has five user roles (Admin, Purchasing, Sales, Warehouse, and Customer). It also holds items for a short time while someone checks out, saves past prices, lets staff check bank transfer payments, creates shipping labels, and makes reports in PDF and Excel (CSV) formats.

Keywords: Inventory control, e-commerce, Laravel 13, MVC architecture, role-based access control (RBAC), Docker, multi-branch management.
\end{_abstract1}
