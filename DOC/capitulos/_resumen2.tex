\begin{_abstract1}
This technical report details the analysis, architectural design, engineering, and deployment of \textbf{\say{Archivum: Bibliotheca \& Discos}}, an integrated enterprise e-commerce and specialized inventory management platform. This technological solution addresses the operational and logistical challenges encountered by boutique establishments specializing in high-value cultural assets, including first-edition rare books, historical vinyl records, and collectible memorabilia. Unlike generic retail platforms, these items demand rigorous custodial tracking, certificates of authenticity (COA), multi-vault inventory synchronization, and immersive catalog browsing powered by a three-dimensional interactive vinyl inspection engine.

To meet these domain requirements, the platform adopts a Model-View-Controller (MVC) software architecture built upon the \textbf{Laravel 11} framework running on \textbf{PHP 8.4}, ensuring high throughput, memory safety, and expressive object-oriented patterns. Data persistence is managed via an enterprise relational database engine, \textbf{MariaDB}, driven by Eloquent Object-Relational Mapping (ORM) with strict relational integrity, indexed foreign keys, and programmatic migrations. The user interface adheres to an archival aesthetic with responsive dark and light modes, engineered using \textbf{Tailwind CSS}, declarative reactivity via \textbf{Alpine.js}, and business intelligence dashboards powered by \textbf{Chart.js}. The entire service topology (Nginx HTTP server, PHP-FPM application container, and MariaDB engine) is encapsulated and deployed using \textbf{Docker} and Docker Compose for deterministic environment isolation and horizontal scalability.

Empirical evaluation indicates a substantial reduction of over 40\% in stock reconciliation latency, comprehensive auditing and end-to-end traceability of inter-branch inventory transfers, rigorous role-based access control (RBAC), and superior customer engagement through modern, responsive web ergonomics.
\end{_abstract1}
